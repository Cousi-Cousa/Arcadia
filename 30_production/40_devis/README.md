# Devis Technique

## Matériel
### Physique
- [Cabinet d'arcade](https://thehomearcade.ca/bartop-arcade-24/) (à commander en ligne)
- Charriot
- Planches en bois (Coupées selon les mesures adéquates)
- Peinture noir
### Technologie
- Ordinateur
- Écran 24 pouces
- 2 boutons d'arcade
- Joystick
- Carte mère (pour connecter les boutons et le joystick)
- Amplificateur
- 2 haut-parleurs
- Multiprise
- Rallonge
- Cable Ethernet
- Cable HDMI
- Cable d'alimentation du moniteur
- Cable d'aliementation de l'ordinateur
